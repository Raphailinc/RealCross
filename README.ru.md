# RealCross

[English](README.md) · [Русский](README.ru.md)

**Архивный учебный проект.** Сохранён как часть истории обучения. Актуальные backend-проекты — в [профиле](https://github.com/Raphailinc).

Статический многостраничный учебный сайт с общей навигацией и оформлением.

## Возможности

- Главная страница, каталог, галерея, информация и контакты.
- Мобильная навигация.
- Проверка полей контактной формы в браузере.

## Локальный запуск

```bash
python -m http.server 8000
```

## Условия запуска и границы проекта

Откройте http://localhost:8000. Серверной отправки формы нет; данные никому не передаются. Автоматические тесты отсутствуют.
